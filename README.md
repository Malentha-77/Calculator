# Calculator

A simple calculator built with HTML, CSS, and JavaScript. It allows users to perform basic arithmetic operations through a clean, straightforward interface.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero error handling
- Empty-input validation
- Clear button to reset the calculator

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
